# Демонстрационные данные

`contracts_demo.xlsx` и `payments_demo.xlsx` содержат полностью вымышленные организации, договоры и суммы. Они предназначены только для демонстрации Femida.

Выберите эту папку в приложении и попробуйте:

| Режим | Запрос | Ожидаемое поведение |
| --- | --- | --- |
| Обычный | `Север` | Строки с ООО Север и ООО Северный проект в обоих файлах |
| Строгий | `ООО Север` | Только строки с полным совпадением названия |
| Строгий | `ДМ-2026-001` | Строки указанного договора |

Двойной щелчок по заголовку столбца открывает дополнительный фильтр. Первая строка каждой таблицы содержит заголовки. Каждый файл имеет один лист.
