# Запуск и диагностика

## Проверка среды

Рекомендуемая версия Python — 3.12. Прямые зависимости закреплены в `requirements.txt`; установка должна выполняться в отдельное виртуальное окружение.

```powershell
.\.venv\Scripts\python.exe --version
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe Femida.py
```

Текущий код ориентирован на Windows: путь к кэшу задан как `C:\excel_cache_app`. Поддержка Linux/macOS не заявляется.

## Частые ситуации

| Симптом | Что проверить |
| --- | --- |
| `ModuleNotFoundError` | Зависимости установлены тем же Python, которым запускается приложение? Используйте путь `.venv\Scripts\python.exe` |
| Команда `py` не найдена | Установите Python 3.12 с Python Launcher либо используйте полный путь к `python.exe` для создания окружения |
| Не удалось создать папку кэша | Нужны права записи в `C:\excel_cache_app`; лучше запросить создание этой папки с правами для вашего пользователя, чем запускать приложение администратором |
| Таблицы не найдены | Выбрана нужная папка? Файлы лежат непосредственно в ней? Расширения — `.xlsx` и `.xls`? |
| Нет данных со второго листа | Текущая реализация читает только первый лист |
| Поиск выдаёт ошибку на `[` или другой спецсимвол | Обычный режим интерпретирует регулярные выражения; используйте строгий режим для полного совпадения |
| Результаты относятся к другому файлу | Возможна коллизия имён кэша; закройте приложение, удалите только содержимое `C:\excel_cache_app` и повторите загрузку |
| Не видны изменения документа | Сохраните файл Excel и обновите выбранную папку; при необходимости очистите кэш после закрытия приложения |
| Окно долго строит результаты | Сократите набор файлов или уточните запрос: отрисовка больших результатов выполняется в основном потоке |

## Какие файлы создаёт приложение

- `C:\excel_cache_app\*.pkl` — локальные копии обработанных таблиц. Удаление кэша приводит к повторному чтению исходных файлов при следующей загрузке.
- `%USERPROFILE%\.excel_search_config\last_folder.txt` — путь к последней выбранной папке. Его удаление сбрасывает автоматический выбор папки.

Удаляйте только указанные файлы приложения, не исходные Excel-документы. Не загружайте чужие Pickle-файлы как кэш.

## Сообщение об ошибке

Укажите версию Windows и Python, команду запуска, текст ошибки из консоли и последовательность действий. Если проблема связана с таблицей, подготовьте маленький пример с вымышленными данными. Персональные и рабочие документы публиковать не нужно.
